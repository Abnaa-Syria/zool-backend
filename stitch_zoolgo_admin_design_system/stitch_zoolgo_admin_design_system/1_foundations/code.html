rounded-lg (8px)
المعيار الأساسي (Medium) الاستدارة القياسية لكافة حقول الإدخال، الأزرار الأساسية، القوائم المنسدلة، وأزرار التنقل.
token: rounded-lg
rounded-xl (12px / 16px)
البطاقات والنوافذ (Large/XL) حاويات الجداول، بطاقات ملخص الرحلة، لوحات الرصيد المالي، والنوافذ المنبثقة التفاعلية.
token: rounded-xl
rounded-full (9999px)
الأقراص والبادجات (Full) شارات حالة الرحلة (مؤكدة، متأخرة، ملغاة)، أرقام المقاعد الدائرية، والصور الشخصية للسائقين.
token: rounded-full
Elevation 0 / Resting shadow-sm

مخصص للبطاقات المستقرة في الصفحة، حاويات الجداول، والحقول غير النشطة. تباين ناعم غير مشتت.
